# 2026-09-05 性能改动与验收

起点：`b80bb6fda90f52014e8c160bd3e7ebaafac99bcb`。改动在 `perf/dice-runtime-20260905` 验证，通过后合入 `master`。环境为 macOS arm64 / Apple M1 Max、Node 24.11.1、pnpm 10.14.0、Chromium 151.0.7922.34。浏览器使用软件 WebGL，不能据此承诺真实手机 FPS。

## 改动

- 碰撞：只在服务端启用 `projected-aabb-v1`，收紧 Heightfield 的三角柱候选范围，保持原始接触方程和顺序。浏览器继续使用 cannon-default，保留实验开关。200 个 seed 的完整 RollRunResult、canonical 初态/终态严格等价；没有改变 THROW v3 / SETTLE v4、步长、求解次数或停稳阈值。
- 渲染：骰子圆角细分由 6 降为 3，主场景三角形由 41,288 降至 32,648（减少 20.9%）。慢帧持续出现时，rolling DPR 逐档降至 1 / 0.75，静态恢复基础分辨率；档位跨轮保留，并用较长恢复窗口避免来回切换。
- 慢放出口：以前每帧 clamp 到 100ms 后丢失的可见墙钟时间不会触发积压错误，长尾 seed 105000 曾出现模拟 8.2 秒、播放约 15.96 秒。一轮可见 clamp 累计丢弃超过 3 秒现在明确报错，不读取运动中骰子、不推进历史；隐藏页面时间另记，不计入此限额。
- 服务端：固定 worker 池在事务外执行共享物理。默认并发 2、排队 32、包括排队的超时 10 秒；队列满、worker 崩溃/超时均拒绝请求。预检和提交复用同一数据库校验，提交时重新判断权限、回合和 deadline；重复命令合并计算，已持久化结果直接重放。服务启动/开发命令构建 `roll-worker.js`，关闭时释放 worker 和连接。
- 入口：单机和多人游戏动态加载，共用 3D chunk。大厅首屏脚本由约 245 KB gzip 降至约 65 KB gzip；进入游戏仍需加载约 178 KB gzip 的 3D 代码。
- UI：单机首轮与结果态保持相同画布高度；多人移动端在画布下放置操作，通过页签查看奖池、全员获取和历史。空历史有提示。rolling 关闭多人面板背景模糊，倒计时仅在秒数变化时更新 React 状态。前次动画忙碌时，新 seed 会在状态变更后重新尝试播放；本机播放异常会明确提示以权威房间记录为准。

## 没有启用的停稳候选

同一批 1000 个 seed：`50000 + i * 1003`，另列历史 watch seeds。10 次迭代为基线，分别对照 20 和 15 次迭代。预先要求 P95/P99 至少改善 10%、倾斜率增加不超过 1 个百分点、穿透不超过 0.1、无安全失败，非自然停稳需继续模拟验证。

| 求解次数 | 批量 P95 | 批量 P99 | 倾斜投掷占比 | 安全异常             | 结论                   |
| -------- | -------- | -------- | ------------ | -------------------- | ---------------------- |
| 10，原值 | 3.067s   | 4.933s   | 5.7%         | seed 991817 异常反弹 | 保留原值与既有异常出口 |
| 20       | 2.533s   | 4.083s   | 6.4%         | seed 935649 异常反弹 | 不启用                 |
| 15       | 2.950s   | 5.683s   | 5.8%         | 无                   | P99 退化，不启用       |

20 次候选的 32 个 watch seeds 中仍有 9.067 秒长尾；15 次候选包含新增失败 seed，共 34 个 watch seeds。基线也存在自然继续模拟耗尽的姿态窗口样本。上述失败不能通过延长 timeout、冻结或移除 seed 掩盖。原值 seed 991817 已补服务端拒绝正常结算的回归断言。

[结构化求解器证据](performance-20260905-solver.json) 保留批量/watch 汇总、继续模拟结果及失败 seed 诊断。20 次实验执行时尚未切换窄相，15 次已使用等价的新窄相，因此 CPU 只可在每组内部比较。求解次数改变会改变轨迹和点数；未来如启用，必须提升物理版本。

复现命令：

```bash
pnpm test:physics:solver-ab -- --seeds=1000 --candidate=20
pnpm test:physics:solver-ab -- --seeds=1000 --candidate=15
```

这些是会对失败候选返回非零退出码的实验，默认运行时未启用候选参数。

## 限制

这次没有宣称物理尾部抖动已经消失。接受的碰撞优化保持轨迹不变；显示负载降低可减少额外慢放。实机 GPU、移动 Safari、持续温升和电池模式仍需设备验收。大厅总首屏资源还包括 CSS 和图片，65 KB 仅指脚本 gzip。构建仍提示 3D chunk 大于 500 KB raw，它已从大厅首屏拆出。
